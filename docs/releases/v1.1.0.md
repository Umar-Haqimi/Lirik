# Lirik 1.1.0

Lirik is a KDE Plasma 6 panel widget that shows what is playing, controls playback and displays
**time-synced, word-by-word lyrics**, both in the panel and in a side panel of the full view.

This release adds a third lyrics source, the [Better Lyrics API](https://docs.betterlyrics.org), and lets you
put all providers in the order you want.

## Highlights

- **Better Lyrics API.** Three new providers, each with its own checkbox, all **on by default**:
  - **Better Lyrics**: word- or line-synced lyrics (TTML). First in the default order.
  - **QQ (Better Lyrics)**: word-synced QRC, strong on Chinese-language music.
  - **Kugou (Better Lyrics)**: line-synced LRC.

  The API only serves songs that are already in its cache. Anything else counts as "not found" and is tried
  again after 6 hours, so a song that shows up there later is picked up on a later play. The three endpoints
  share one rate limit, so with all three on a track costs up to three requests there. Results are credited as "Lyrics from <name>" with a link to
  [better-lyrics.boidu.dev](https://better-lyrics.boidu.dev).
- **Drag-and-drop provider priority.** The Lyrics settings page has one list of providers with a checkbox per
  row. Drag rows (or press Alt+Up / Alt+Down on a focused row) to set the order, top first. This replaces
  "Ask Unison first". Unticked rows keep their place, so ticking one again puts it back where it was.
  The default order is Better Lyrics, Unison, LRCLIB, QQ, Kugou.
- **Strict order, if you want it.** By default better-synced lyrics still win (word > line > plain) and the order
  breaks ties. Turn on **Always use the highest provider that has lyrics** and the order decides first: plain
  lyrics from your top provider beat word-synced lyrics from a lower one.
- **Fair ties.** Results of equal rank now go to the provider higher in your list instead of whichever answered
  first.

## Before you upgrade

- **Privacy:** if you never changed the provider settings, Lirik now uses the new default
  (all five providers, Better Lyrics first) and **starts sending lookups to `api.betterlyrics.org`** (title,
  artist, album and duration, as with the other providers; up to three requests per track, one per endpoint).
  To opt out, untick **Better Lyrics**, **QQ** and **Kugou** in Settings → Lyrics. If you had saved a provider
  list, it is kept exactly as it was.
- Your saved settings carry over; "Ask Unison first" becomes the matching order in the new list.
- Lyrics already in the cache are not re-ranked when you change the order. Use **Clear cache** on the Lyrics
  page to re-rank them right away.
- The new settings strings are in English only for now. Translations are welcome (see `TRANSLATIONS.md`).

## Install or upgrade

Needs KDE Plasma 6.0.4 or newer. Developed and tested on Plasma 6.8 / Qt 6.12 (Arch, Wayland).

Download `lirik-1.1.0.plasmoid` from this release, then upgrade an existing install:

```sh
kpackagetool6 -t Plasma/Applet -u lirik-1.1.0.plasmoid
```

or install it fresh:

```sh
kpackagetool6 -t Plasma/Applet -i lirik-1.1.0.plasmoid
```

Then right-click the panel, choose **Add Widgets**, search for "Lirik" and drag it onto the panel or desktop.
To remove: `kpackagetool6 -t Plasma/Applet -r my.umarh.lirik`.

## Known limitations

- "Try next match" cannot reach a different version from the Better Lyrics API (it returns no version ids),
  only a version from another provider.
- Lyrics are matched on title, artist, album and duration (plus a YouTube id when the cover-art URL
  reveals one). Exact Spotify or YouTube id lookups are planned.
- Panel lyrics are not shown in vertical panels. The widget still works there.
- Translations and romanization carried by the lyrics are parsed but not shown yet.

## Verification

The Node test suite (541 tests: parsers including the new QRC parser, providers, resolver and ranking, stub
server, security, package checks) passes, and `bin/i18n check` confirms the translation template matches the
sources. The settings page has a new QML test (`tests/qml/tst_configpage.qml`) that drags a list row with the
real mouse path.
