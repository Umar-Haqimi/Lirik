# Lirik

A KDE Plasma 6 panel music widget with time-synced, word-by-word lyrics.

Lirik is a fork of [PlasMusic Toolbar](https://github.com/ccatterina/plasmusic-toolbar) by Claudio
Catterina (GPL-3.0). It keeps everything upstream does and adds lyrics from
[LRCLIB](https://lrclib.net) and [Unison](https://unison.betterlyrics.org).

> Work in progress. See `docs/SPEC.md` for the design and `docs/PROGRESS.md` for status.
> Upstream's README is kept as `README.upstream.md`.

Lyrics belong to their respective owners. Lirik does not ship or store lyrics in this repository.
